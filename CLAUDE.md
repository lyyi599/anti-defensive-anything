# CLAUDE.md

Conventions for maintaining this repository. Project overview: README.md. Development workflow: README_dev.md.

The working language is **English**. Write skills, docs, scripts, commit messages, and grader rubrics in English. Reply to the user in whatever language they use.

## Structure

- `skills/anti-defensive/` holds the core principles + routing table; scene skills live in `skills/anti-defensive-<scene>/`.
- Every scene skill has five sections: one-line principle → defensive signals → rules → before/after → must keep. Start new scenes from `templates/SKILL.template.md`.
- Every scene skill must point to `../anti-defensive/SKILL.md` at the top; a new scene needs a routing-table row and at least one `<scene>-*` case in `evals/`.

## Rules for changes

- **Never weaken the honesty floor.** Anti-defensive ≠ overclaiming: decision-changing risks, unverified items, and unknowns must stay. Any change that makes a skill more likely to overclaim, hide, or fabricate is wrong.
- Changing a rule changes model behavior. After editing `skills/`, run the relevant scene's evals and describe the behavior change under `[Unreleased]` in `CHANGELOG.md`.
- **Skills must not contain eval content** (dataset names, numbers, sentences). Use examples from a different domain, or the eval tests copying instead of the rule.
- Skill `description`s keep bilingual trigger words (English + Chinese) so Chinese requests still trigger them.
- Languages: English files are the source. `README_CN.md` and `prompts/quick-prompt-zh.md` are generated by `scripts/translate.py` — **never edit them by hand**. After editing a source, run `python3 scripts/translate.py`; add new files to translate to `PAIRS` in that script.
- Eval case prompts stay in Chinese on purpose (they test Chinese-speaking users); rubrics are English.
- Releasing: bump `version` in both `plugin.json` and `marketplace.json`, and turn `[Unreleased]` into the version and date.
- Logo: change only `PARAMS` in `assets/src/gen_logo.py`, then run the script; don't hand-edit `assets/logo.svg`.

## Before committing

```bash
python3 scripts/validate.py              # also warns about stale translations
python3 scripts/translate.py             # when README.md or prompts/quick-prompt.md changed
claude plugin validate .
claude plugin eval . --case '<scene>-*'  # the scene you changed
```
